# Car Repair Platform

A platform that connects car owners with mechanics and provides fast car repair assistance.

## 🚗 What is this?

Car Repair Platform helps people find mechanics when their car breaks down.

## 🎯 Main Features

- Find nearby mechanics
- Get repair consultation
- Video consultation
- Mechanic verification
- Online payments
- Mechanic profiles
- Car repair information

## 🚀 Goal

Our goal is to make car repair faster, easier and more accessible.

## 📌 Project Status

🚧 Currently under development.
## 🔧 Mechanic Search

Users will be able to find available mechanics based on their location and car type.
